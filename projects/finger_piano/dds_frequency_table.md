# DDS 频率表(正弦音频扩展,与方波 `frequency_table.md` 分开维护)

> 本表描述 **DDS 正弦发生器**(`src/audio/dds_sine_generator.v`)的数学真值。
> 方波 `tone_generator` 的整数分频表在 [frequency_table.md](frequency_table.md),
> 两者**分别维护、不得混写**,报告中可对照"基础功能:整数分频方波 /
> 扩展功能:DDS 正弦波"。

## 1. 标称频率来源

七个音符使用课程资料的**两位小数标称频率**(注意:与方波模块为整数运算
采用的 0.1 Hz 近似不同,DDS 直接使用两位小数):

| note | f_nom (Hz) |
|---|---|
| C4 | 261.62 |
| D4 | 293.67 |
| E4 | 329.63 |
| F4 | 349.23 |
| G4 | 391.99 |
| A4 | 440.00 |
| B4 | 493.88 |

## 2. DDS 参数(冻结)

| 参数 | 值 |
|---|---|
| 采样率 SAMPLE_RATE_HZ | 8000(8 kS/s,复用 `CFG_DAC_SAMPLE_RATE`,不建第二真值源) |
| 相位累加器 PHASE_BITS | 24(2^24 = 16 777 216) |
| 相位地址 | 8 bit(256 相位位置,quarter-wave LUT 65×11 bit) |
| DAC 样点 | 12 bit unsigned,center = 2048(12'h800),幅度 = 1792 |
| 数字输出范围 | 256 ~ 3840(12'h100 ~ 12'hF00,两端留余量,不用满轨) |
| 静音值 | 2048(12'h800,零交叉/中点,避免静音时的直流阶跃) |
| 频率步进分辨率 | 8000 / 2^24 ≈ 0.000477 Hz(远优于 1% 指标) |

## 3. Phase increment 公式

```
phase_inc = round( f_nom × 2^24 / 8000 )
```

8 kS/s、24-bit 相位累加器下的七个音符:

| note | f_nom (Hz) | phase_inc (十进制) | phase_inc (十六进制) | DDS 理论频率 (Hz) | 理论误差 |
|---|---|---|---|---|---|
| C4 | 261.62 | 548 657 | 24'h085F31 | 261.620045 | +0.000 017 % |
| D4 | 293.67 | 615 871 | 24'h0965BF | 293.670177 | +0.000 060 % |
| E4 | 329.63 | 691 284 | 24'h0A8C54 | 329.629898 | −0.000 031 % |
| F4 | 349.23 | 732 388 | 24'h0B2CE4 | 349.229813 | −0.000 054 % |
| G4 | 391.99 | 822 063 | 24'h0C8B2F | 391.990185 | +0.000 047 % |
| A4 | 440.00 | 922 747 | 24'h0E147B | 440.000057 | +0.000 013 % |
| B4 | 493.88 | 1 035 741 | 24'h0FCDDD | 493.879795 | −0.000 042 % |

验收标准仍按课程指标:**|误差| < 1%**(实际优于 0.001%)。
TB 用 real 独立重算 `round(f_nom × 2^24 / 8000)` 与 DUT 选择的 increment
对照,并另外用输出样点零交叉统计独立测频,双重验证。

## 4. 采样节拍(12 MHz 板上配置)

```
SAMPLE_DIV = SYS_CLK_HZ / SAMPLE_RATE_HZ = 12 000 000 / 8000 = 1500
```

本阶段 **12 MHz / 8 kHz 是精确整除配置**;第一版不实现任意非整除的
fractional-N sample enable。每 1500 个 clk 产生一次 1 clk 宽的
`sample_tick`/`dac_code_valid`,**不生成 clk_8k 等第二时钟**,所有时序
逻辑都在 `posedge clk` 域内以 clock-enable 方式更新。

音符切换只复位相位,**不重启采样分频器、不改变 8 kS/s 节拍**;静音
(note=0)时仍按 8 kS/s 持续输出 12'h800,使后续 MCP4725 流水线保持
固定节拍。

## 5. Quarter-wave LUT

幅度表 `M[k] = round(1792 × sin(kπ/128)),k = 0..64`(65 × 11 bit,
0°~90°),完整 256 相位由四象限对称合成:

| quadrant(phase_addr[7:6]) | 相位范围 | 计算 |
|---|---|---|
| 0 | 0°~<90° | 2048 + M[index] |
| 1 | 90°~<180° | 2048 + M[64−index] |
| 2 | 180°~<270° | 2048 − M[index] |
| 3 | 270°~<360° | 2048 − M[64−index] |

关键点:phase 0 → 2048,phase 64 → 3840,phase 128 → 2048,phase 192 → 256。
半周期反对称 `code[p] + code[p+128] = 4096`(±1 LSB),四分之一波单调不减。

## 6. 注意事项

- **本表只适用于 8 kS/s**。如果将来修改 `CFG_DAC_SAMPLE_RATE`,必须按
  第 3 节公式重新生成七个 increment,**不能**只改采样率宏而沿用旧表
  (RTL 常量表不会自动跟随宏变化)。
- 第一版不做"任意采样率自动计算 increment"(f×2^24 在 32 位 integer
  常量表达式中有溢出/类型陷阱,7 个固定音没有泛化的必要)。
- LUT 是常量查表;禁止 CORDIC / Taylor / 实时乘法 sin,禁止在综合 RTL
  中使用 real / $sin / 运行时文件生成(测试代码可以用 real 独立复核)。
- 第一版固定 12 bit 输出、固定幅度 1792,不做动态音量缩放(避免乘法器,
  压力音量将来另加 audio_gain 层)。
