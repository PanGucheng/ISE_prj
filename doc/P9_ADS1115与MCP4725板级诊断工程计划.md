## 8. dbg_alive

P110 输出 `dbg_alive`。

建议为：

```text
约 1 Hz 或 2 Hz heartbeat
```

由 12 MHz 主时钟同步计数产生 GPIO 翻转。

禁止把 heartbeat 当内部时钟。

其唯一意义是：

```text
FPGA configured
clock running
reset released
top-level alive
```

它不代表 ADC/DAC PASS。

---

## 9. dbg_adc

P111 输出 `dbg_adc`。

推荐语义：

> 每完成一个完整 ADS1115 三通道 frame，翻转一次。

不要直接输出 1 个 12 MHz 周期宽度的 `adc_sample_valid`，因为板上不容易观察。

推荐：

```text
complete ADC frame
      ↓
toggle dbg_adc
```

---

## 10. dbg_error

P113 输出 sticky error：

```text
dbg_error = adc_error OR dac_error OR dac_overrun
```

一旦发生任意错误：

```text
dbg_error = 1
```

保持到下一次 reset。

第一版不做复杂 blink code / Morse code / 多错误编码。

## 12. ADS1115 输入原则

第一轮板测不要求 FSR 完整标定。

可选择：

```text
AIN0 → GND
AIN1 → 已知分压
AIN2 → 另一已知分压
```

或使用真实 FSR 前端。

P9 RTL 不依赖具体输入电压。

P9 只验证：

```text
通信存在
转换存在
完整 frame 持续形成
```

不完成压力校准。

## 13. MCP4725 诊断模式

建议实现 compile-time / parameter：

```text

```

不新增 mode pin。

推荐四种模式：

```text
MODE 0 = 0x800 中点 DC
MODE 1 = 0x400 低值 DC
MODE 2 = 0xC00 高值 DC
MODE 3 = 1 kHz / 8 kS/s 周期波形
```

## 14. DAC DC 模式

### 0x800

理论：

```text
VOUT ≈ VDD/2
```

若 VDD=3.3V，约 1.65V，仅作为理论参考，实际值必须由用户测量。

### 0x400 / 0xC00

用于确认：

```text
0x400 < 0x800 < 0xC00
```

对应 VOUT 单调增加。

P9 软件不得提前声称实际电压合格。

## 28. 独立项目 warning policy

P9 不使用正式 `finger_piano` 的 166-warning allowlist。

> **P9-E 修正（实际结果口径）**：诊断顶层刻意不消费 ADS1115 转换值
> （§12）且 `DAC_TEST_MODE` 是编译期常量（DC 模式使 DAC 载荷恒定），
> XST 对这些结构的 trim 是**结构性的**，无法在不改动 driver 例化语义
> 的前提下消除。实际结果：**144 条 synthesis warnings，全部逐行人工
> 审核并折入本工程自己的精确 allowlist（逐条 id+pattern+expected）；
> unexpected warnings = 0；latches = 0；XST errors = 0**。任何新
> warning、路径变化或计数漂移仍判 FAIL。正式 `finger_piano` 的
> 166-warning allowlist **未修改**，两个工程的 allowlist 互不相干。

## 33. 推荐板测顺序（用户执行）

### Step 1 — 最小接线

只连接：

```text
FPGA
ADS1115
MCP4725
```

暂时不接 LM386 / speaker。

### Step 2 — JTAG volatile program

用户明确授权后写入 P9 bitstream。

先观察：

```text
P110 dbg_alive
```

如果 heartbeat 不存在，优先查 FPGA / clock / reset，不查 I2C。

### Step 3 — 检查 sticky error

若：

```text
P113 = 1
```

说明至少一个外设事务曾失败。

用逻辑分析仪分别检查：

```text
P31/P32
P102/P103
```

### Step 4 — ADS activity

观察：

```text
P111 dbg_adc
```

如果 heartbeat 正常但 P111 不动，优先检查 ADS1115 地址、供电、上拉和 ACK。

### Step 5 — 测 DAC DC

依次测：

```text
0x400
0x800
0xC00
```

确认 VOUT 单调。

### Step 6 — 测 1 kHz

测 MCP4725 VOUT：

```text
中心
幅值
频率
8 kS/s staircase
```

### Step 7 — 再接重构滤波

比较：

```text
滤波前 staircase
滤波后 smoother waveform
```

LM386 不属于本阶段。
