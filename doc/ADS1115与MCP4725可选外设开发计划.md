# finger_piano 可选 ADC/DAC 驱动基础设施

## 本阶段目标

为 `projects/finger_piano` 增加经过 ISim 仿真的 **ADS1115 / MCP4725 可选驱动基础设施**。默认配置两个外设都关闭，**不启用**模拟采集、不改方波音频路径、不猜 I²C 管脚、不实现 DDS。

**当前软件基线（legacy baseline）** 保持不变：

`LM393 → key_in[6:0] → 同步/滤波 → 7 路优先级编码器 → 整数分频方波 → audio_out`

这是为了不破坏已验证课设路径而保留的 **7 键 RTL**。它 **不是** 最终硬件形态。真实板卡是 **3 个 LM393 数字输出组成 3-bit 编码**（见下文「后续架构迁移」）。本阶段不得把 7 键路径改成 3-bit 译码。

验收主入口仍是：

```powershell
pwsh -File .\ise.ps1 verify -Project finger_piano
```

必须：现有 6 个仿真继续 PASS；默认综合 0 error / 0 warning；implement 不被新端口拖垮。

## 明确不做

- 不把 `CFG_ENABLE_ADS1115` / `CFG_ENABLE_MCP4725` 设为 1
- **不把这组宏写成“只改一处即可启用系统”**（见「ENABLE 宏语义」）
- 不改 `tone_generator` / `audio_out`，不引入 `AUDIO_MODE` / DDS / 正弦 LUT
- 不写 MCP4725 EEPROM（禁止 `C2,C1,C0 = 0,1,1`）
- 不用 ADS1115 `ALERT/RDY`，不用 Hs-mode（3.4 MHz）
- 不把压力判断、音符编码塞进 ADC driver
- **不给 `adc_i2c_*` / `dac_i2c_*` 填 UCF LOC**（BOARD TODO）
- 不改工具链、不烧录、不改现有 7 路数字键引脚
- **不把 7 路优先级编码器改成 3-bit 二进制译码**（上板前另一次迁移，本阶段禁止）
- 不把任务书示例的 2 MHz 时钟套到本工程（板上是 **12 MHz / P57**）
- 不把板上默认 I²C 做成刚好 400 kHz；不在 `i2c_master` 里区分地址 NACK / 数据 NACK
- 不用 latest-value-wins 作为 MCP4725 的默认缓冲策略

## 手册核验结果（实现必须用这些，不得照抄任务书十六进制）

### ADS1115（`doc/ads1115.pdf`）

- 开漏 I²C；SDA/SCL 必须外接上拉；器件不 clock-stretch。
- Fast-mode：`f_SCL ≤ 0.4 MHz`，`t_LOW ≥ 1300 ns`，`t_HIGH ≥ 600 ns`，`t_BUF/t_HD;STA/t_SU;STO ≥ 600 ns`。
- ADDR=GND → `1001000b = 7'h48`（VDD=`7'h49`，SDA=`7'h4A`，SCL=`7'h4B`）。地址必须参数化。
- Pointer：`00` Conversion，`01` Config。字节 MSB first。读转换：写 pointer `00` → Repeated START → 读 2 字节，最后一字节 Master NACK。
- Config（ADS1115 图 8-5）：`OS | MUX[2:0] | PGA[2:0] | MODE | DR[2:0] | COMP_MODE | COMP_POL | COMP_LAT | COMP_QUE[1:0]`。
- 本阶段默认：OS=1，PGA=`001`（±4.096 V），MODE=1（single-shot），DR=`111`（860 SPS），比较器关闭（`COMP_QUE=11`，其余 COMP=0）。
- 单端：AIN0/1/2→GND 的 MUX 为 `100/101/110`。
- **由位域自行拼出（与任务书一致，但是核验结论不是抄写）：**
  - CH0 = `16'hC3E3`
  - CH1 = `16'hD3E3`
  - CH2 = `16'hE3E3`
- 结果为 16-bit two's complement；driver **原样输出**，不把负数钳 0。
- 转换完成用 **读回 Config.OS**（0=进行中，1=就绪）+ timeout；860 SPS 标称约 1.2 ms，DR 容差 ±10%，timeout 必须大于该值，禁止只硬等固定周期。
- 模拟输入绝对值仍不得超过 VDD（3.3 V 供电时不能因为 FSR=±4.096 V 就输入 4.096 V）。

### MCP4725（`doc/MCP4725.pdf`）

- 开漏 I²C；Fast-mode `f_SCL ≤ 400 kHz`，`t_LOW ≥ 1300 ns`，`t_HIGH ≥ 600 ns`，**`t_BUF ≥ 1300 ns`（比 ADS 更严）**。
- 器件码 `1100`；A2/A1 出厂硬连线（未指定则为 00）；A0 由引脚决定。默认假设 A2A1=00、A0=0 → `7'h60`，**必须可配置，禁止写死不可改。**
- **只允许 Fast Write（表 6-2：C2=0, C1=0）**：只改 DAC Register，EEPROM 不变。
- 帧：`START | addr+W | ACK | {2'b00, PD1, PD0, D[11:8]} | ACK | D[7:0] | ACK | STOP`。正常模式 PD1=PD0=0。
- `dac_code=12'hABC` → byte1=`8'h0A`（`00_00_1010`），byte2=`8'hBC`（`1011_1100`）。
- VOUT 在**第三个字节 ACK 下降沿**更新（图 6-1 注 2）。
- `VOUT = VDD * D / 4096`。禁止写 EEPROM（典型 25 ms / 最大 50 ms，且有擦写寿命）。
- Fast Write 每次 = 地址字节 + 两个数据字节。在 400 kHz 或约 333 kHz 下都足以支撑 8 kS/s。
- 本阶段不做 Hs-mode、不做读命令、不做广播。

### I²C 拍数算法（写死，禁止只写“向上取整并钳制”）

任务书 2 MHz 的 LOW=3 / HIGH=2 **不适用**。`T_clk = 83.33 ns`。

若分别对 `t_LOW`、`t_HIGH` 向上取整再相加，12 MHz 会得到 16+8=24 拍 = **500 kHz**，超过 Fast-mode `f_SCL ≤ 400 kHz`。因此必须按下面三步，不得简化。

**强制公式**（`tLOW_MIN` / `tHIGH_MIN` 为秒，`SYS_CLK` / `I2C_HZ` 为 Hz）：

```
LOW    = ceil(tLOW_MIN  * SYS_CLK)
PERIOD = ceil(SYS_CLK   / I2C_HZ)
HIGH   = max( ceil(tHIGH_MIN * SYS_CLK), PERIOD - LOW )
```

ADS Fast-mode：`tLOW_MIN=1300 ns`，`tHIGH_MIN=600 ns`。MCP Fast-mode 相同的 LOW/HIGH 下限，但 `t_BUF ≥ 1300 ns`（比 ADS 的 600 ns 更严），START/STOP/BUF 等待按实例独立参数计算。

**Verilog-2001 32 位 integer 溢出（硬约束）**：

禁止 `SYS_CLK_HZ * 1_300_000_000`，也禁止 `SYS_CLK_HZ * 1300`（`12_000_000 * 1300 = 15.6e9`，已超出 32 位有符号上限 2_147_483_647）。必须先除后取整：

```
// ceil(SYS_CLK_HZ * T_NS / 1_000_000_000) 的安全写法：
//   Q = 1_000_000_000 / T_NS;              // T_NS 为 600 或 1300，Q 拟合
//   CYCLES = (SYS_CLK_HZ + Q - 1) / Q;     // ceil(SYS_CLK_HZ / Q)
localparam integer Q_LOW  = 1000000000 / 1300;   // 769230
localparam integer Q_HIGH = 1000000000 / 600;    // 1666666
localparam integer LOW    = (SYS_CLK_HZ + Q_LOW  - 1) / Q_LOW;
localparam integer PERIOD = (SYS_CLK_HZ + I2C_HZ - 1) / I2C_HZ;
localparam integer HIGH_MIN = (SYS_CLK_HZ + Q_HIGH - 1) / Q_HIGH;
localparam integer HIGH   = (HIGH_MIN > (PERIOD - LOW)) ? HIGH_MIN : (PERIOD - LOW);
```

`ceil(SYS_CLK_HZ / floor(1e9/T_NS))` 相对真实 `ceil(SYS_CLK_HZ*T_NS/1e9)` 略保守，对最短脉宽是安全方向。

公式在 12 MHz 下的数字合法点（**不是板上默认**）：

| 目标 `I2C_HZ` | LOW | PERIOD | HIGH | `f_SCL` |
|---|---|---|---|---|
| 400000 | 16（1333 ns） | 30 | 14（1167 ns） | 400 kHz |
| 333333 | 16 | 36 | 20 | 333.33 kHz |

### 板上默认速率：约 333 kHz，不要卡在正好 400 kHz

16+14 在数字上满足手册 Fast-mode 下限，但 **没有** 给模块上拉、总线电容和 SCL/SDA 上升沿留裕量。ISim 的 `pullup` 只模拟逻辑上拉，**不能** 模拟真实 4.7 kΩ + 电容的上升时间。

- **默认目标**：约 300～333 kHz。12 MHz 下默认拍数取 **18+18**（各 1500 ns）→ `f_SCL = 333.33 kHz`。LOW=18 ≥ 公式下限 16，HIGH=18 ≥ 600 ns，周期 36 拍 ≥ `ceil(12e6/333333)`。
- **400 kHz（16+14）保留为可配置项**，不是实物默认。
- 对未来 8 kS/s DAC：Fast Write 约 3 字节。333 kHz 下一次事务约 90 µs 量级，样点周期 125 µs，裕量足够。

`CFG_ADC_I2C_SPEED` / `CFG_DAC_I2C_SPEED` 默认 **333333**。实现时 12 MHz 默认路径必须落到 18+18，而不是把公式在 400 kHz 的 16+14 当默认。

## 架构

```
                    ┌─ i2c_master (ADC 实例) ─ adc_i2c_scl/sda ─ ADS1115
ads1115_ctrl ───────┘     独立 FSM / busy / error / timeout / 时序参数

                    ┌─ i2c_master (DAC 实例) ─ dac_i2c_scl/sda ─ MCP4725
mcp4725_ctrl ───────┘     独立 FSM / busy / error / timeout / 时序参数
```

- 同一份 `i2c_master.v`，**两个完全独立实例**。禁止总线仲裁器、禁止共享 transaction scheduler。
- 开漏：`assign sda = sda_drive_low ? 1'b0 : 1'bz;`（SCL 同理）。**不得输出逻辑 1。**
- 全工程仍只有时钟域 `clk`；SCL 是开漏 IO，不是第二时钟。

### ENABLE 宏语义（driver default enable / integration-ready）

**本阶段不改 `finger_piano_top` 端口，不改 UCF，不在顶层实例化外设。** 这是安全策略：四个 I²C GPIO 尚未确认，不能让 ISE 自动分配管脚。

因此 `CFG_ENABLE_ADS1115` / `CFG_ENABLE_MCP4725` 只是 **driver 默认使能 / integration-ready 配置**，供 controller 模块自身的 `ENABLE` 参数和独立 TB 使用。

**把其中任一宏改为 1，并不能真正启用硬件。** 禁止写成“只改这一处宏即可启用系统”。真正启用必须 **同时** 完成下面三项（本阶段全部不做）：

1. `finger_piano_top` 增加 `adc_i2c_scl/sda`、`dac_i2c_scl/sda` 四个 `inout` 端口  
2. 顶层实例化 `ads1115_ctrl` 与 `mcp4725_ctrl`（两个独立 `i2c_master`）  
3. 用户确认后的 **4 个真实 UCF LOC**（禁止猜测、禁止 MAP 自动分配）

本阶段：

- `src/finger_piano_cfg.vh` 增加开关与参数，**默认全 0**。
- driver / master 作为可综合 RTL 列入 `project.json` 的 `sources`（让 XST 编译、尽早暴露 Verilog-2001 问题），但顶层 **不实例化** → 默认网表 I/O 仍为 20，方波路径二进制等价。
- 功能与“feature off 无总线活动”由 **独立 testbench** 证明。

## 模块规格

### `i2c_master.v`（Verilog-2001）

- 参数：`SYS_CLK_HZ`，`SCL_LOW_CYCLES`，`SCL_HIGH_CYCLES`，以及 START/STOP/BUF 周期、timeout 周期。
- 命令级接口（valid/ready）：`START / RESTART / WRITE_BYTE / READ_BYTE / STOP`。读字节带 `nack_after`（最后一字节 Master NACK）。
- **Master 不知道当前字节是地址还是数据**（接口只有 `WRITE_BYTE`）。因此底层 **只报告 NACK，不区分 ADDR_NACK / DATA_NACK**。禁止为了错误码把通用 I²C Master 做成协议相关。
- Master `error_code`：`0 none / 1 NACK / 2 timeout / 3 protocol/internal`。NACK 时 abort → STOP（或释放总线）→ `error_code=1`。
- timeout：位周期或 ACK 等待超时 → 释放 SDA/SCL → `error_code=2`。
- `busy`；复位后 `sda_drive_low=0`、`scl_drive_low=0`（总线释放）。
- 单时钟 `posedge clk`，异步复位只用传入的 `rst_n_sync`。
- 不用 `$clog2` / `logic` / `always_ff` / `automatic`；计数器位宽用常量 localparam。

### `ads1115_ctrl.v`

- 实例化 **一个** `i2c_master`。参数：`ENABLE`、`I2C_ADDR`、`PGA`、`DR`、`SYS_CLK_HZ`。
- 配置字在模块内按手册位域拼接，TB 断言结果为 C3E3/D3E3/E3E3（默认 PGA/DR 时）。
- FSM：`IDLE → CONFIG_CHn → WAIT_OS_CHn → READ_CHn`（n=0,1,2）→ `SAMPLE_DONE` → 循环。
- WAIT：写 Config（pointer `01` + 16-bit）后反复读 Config，直到 OS=1 或 timeout。
- 输出：`adc_ch0/1/2_raw[15:0]`，`adc_sample_valid`（三路一轮完成脉冲），`adc_busy`，`adc_error`，`error_code[2:0]`。
- **Controller 根据自身 FSM 映射错误码**：地址字节 NACK → `1 ADDR_NACK`；数据/pointer 字节 NACK → `2 DATA_NACK`；master timeout → `3`；其它 → `4`。不要让 master 做这个映射。
- `ENABLE=0`：FSM 停在复位/IDLE，不发任何 I²C，`adc_sample_valid=0`，SDA/SCL 保持 Z。
- 不含按键/音符逻辑。不用 ALERT/RDY。

### `mcp4725_ctrl.v`

- 实例化 **另一个** `i2c_master`。参数：`ENABLE`、`I2C_ADDR`、`SYS_CLK_HZ`。
- 接口：`dac_code[11:0]`，`dac_code_valid`，`dac_code_ready`，`dac_busy`，`dac_error`，**`dac_overrun`**。
- 只发 Fast Write。硬约束：命令字节高 2 位恒 `2'b00`；TB 扫描总线禁止出现 EEPROM 命令（`C2C1C0=011` 或 3 字节数据载荷的写 EEPROM 帧）。
- **缓冲策略 = 一项 pending buffer + overrun flag，禁止 latest-value-wins。**  
  latest-value-wins 适合设定电压；DDS 每个 8 kS/s 样点都有意义，静默丢点会造成波形失真。  
  - `dac_code_ready` 在 pending 空闲时为 1。  
  - 接受的样点进入唯一 pending 槽，发完才清。  
  - `valid && !ready` → 置 `dac_overrun`，**不覆盖**已挂起的样点（新样点被拒绝）。  
  - 正常 8 kS/s 必须 **零丢样 / 零 overrun**；只有生产者超过总线吞吐时才报 overrun。
- Controller 同样根据 FSM 把 master 的 NACK 映射为 ADDR_NACK 或 DATA_NACK。
- `ENABLE=0`：不传输、不影响 `audio_out`（本阶段本就不接音频）。

Controller 对外错误码：`0 none / 1 ADDR_NACK / 2 DATA_NACK / 3 timeout / 4 protocol`。外设未接时必须退出，禁止卡死。

协议类用例可用 TB 参数降频（如 1 MHz）并按比例改 SCL 周期。**吞吐用例必须按 12 MHz + 目标 I²C 速率跑**，不能降频后宣称 8 kS/s 裕量。ISim 里用 `pullup` 模拟逻辑上拉，并在文档写明它 **不是** 4.7 kΩ 上升沿模型。

### `tb_i2c_master`

START/STOP/Repeated START、写/读字节、ACK/NACK（底层只报 NACK，不报 ADDR/DATA 细分）、开漏（驱动侧只出现 0/Z）、timeout 退出、复位后总线释放。

### `tb_ads1115_ctrl`（任务书 §28）

协议模型返回 AIN0=`16'h1234`、AIN1=`16'h3456`、AIN2=`16'h5678`。自动检查：地址 `7'h48`、三路配置字、pointer `01`/`00`、Repeated START、MSB/LSB、三路寄存器、地址 NACK 与数据 NACK 分别映射、timeout 退出、`ENABLE=0` 时 SCL/SDA 无边沿。

### `tb_mcp4725_ctrl`（任务书 §29 + 吞吐）

1. 依次发送 `000/800/FFF/123/ABC`，检查 Fast Write 拆分、地址、ACK、STOP、busy/ready、NACK 恢复（ADDR vs DATA 由 controller 映射）、**无 EEPROM 命令**、`ENABLE=0` 无总线活动。  
2. **吞吐**：`SYS_CLK_HZ=12_000_000`，I²C 为默认 ~333 kHz（18+18）。以 8 kHz 连续送入 **至少 100 个** 样点。必须 `overrun==0`、发出帧数 == 输入样点数（0 drop）。可另做一拍过载刺激，确认 `dac_overrun` 置位且 pending **不被覆盖**。

模型只需协议，不需要模拟电路。

现有 6 个仿真 **零改动**（顶层端口不变，7 键 legacy 路径不变）。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 未实例化模块仍被 XST 编译出 warning，触发 `failOnSynthesisWarnings` | 写纯 Verilog-2001；D 阶段看 `synthesis.srp`，有 warning 立刻改 |
| ISim 对 `inout`/`pullup` 行为与 FPGA IOBUF 不完全相同 | TB 同时检查 drive-low 内部信号与总线线网；文档写明 pullup ≠ 4.7 kΩ 上升沿 |
| 分别 ceil(tLOW)+ceil(tHIGH) 得到 500 kHz | 强制 PERIOD 公式；默认 18+18 而不是 16+8 或 16+14 |
| `SYS_CLK_HZ * 1300` 溢出 32 位 | 先算 `Q = 1e9 / T_NS`，再 `(SYS_CLK_HZ + Q - 1) / Q` |
| latest-value-wins 让未来 DDS 丢样 | pending + overrun；12 MHz 吞吐 TB 卡零丢样 |
| 有人把 ENABLE=1 当成系统已启用 | 顶层本阶段无端口、无实例化；文档把三项硬条件写死 |
| 后续 Agent 把 7 键 RTL 当成最终硬件 | 本文与 ADC_DAC 文档把 legacy baseline / 3-bit 迁移写成独立后续项 |
